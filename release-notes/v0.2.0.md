# remote-compose v0.2.0 — first PyPI release

The `rc` CLI is now installable directly from PyPI:

```bash
pip install remote-compose          # core
pip install "remote-compose[ecs]"   # adds python-hcl2 for terraform validation
```

After install, `rc --help` shows the full command tree.

## What's in this release

### Deploy
- `rc up [--from-compose <docker-compose.yml>] [--domain <fqdn>] [--ttl <duration>]`
  scaffolds a v2 rc.yml on the fly when none exists, deploys via terraform,
  pushes secrets, prints the ALB URL.
- `rc deploy [--no-state]` — code-only redeploys. `--no-state` skips
  terraform entirely and just rebuilds + pushes images + force-rolls
  services; ECR repos are auto-discovered via `describe-repositories`
  (handles legacy single-flat-namespace and renamed-project setups).
- `rc destroy`, `rc reap`, `rc plan`, `rc status`, `rc logs`, `rc restart`,
  `rc exec` — full lifecycle.

### Migrate from v1
- `rc v1 migrate plan <v1-rc.yml>` — read live AWS state, generate v2
  rc.yml + migration summary, no AWS writes.
- `rc v1 migrate apply <v1-rc.yml>` — boto3-only cutover: register
  v2-shaped task defs (`secrets[]` referencing SM ARNs), rolling-update
  each service. EFS / ALB / ACM / SM / DNS untouched.

### Adopt existing stacks
- `rc adopt` — bring an existing AWS stack under terraform management.
  Walks resources via boto3, generates import blocks. Idempotent.

### Hot reload
- `rc dev push` + `rc dev pull` — sync local source into the deployed
  task via EFS dev-mode volumes. Iterate without rebuilding the image.

### Other
- `rc compose import` — translate a docker-compose.yml to rc.yml v2.
- `rc copilot import` — port AWS Copilot manifests to rc v2.
- `rc fix nginx-conf` — generate ECS-aware nginx.conf with VPC resolver.
- `rc db push` / `rc db dump` — pg_dump round-trip.
- `rc lifecycle` / `rc exec` — invoke named hooks (migrate,
  createsuperuser, etc.) inside a running task.

## Verified end-to-end (debuggai profile, account 033937118837, us-west-2)

- Hybrid v1+v2 deploys: `rc deploy --no-state` against `ss-debuggai-prod`
  built+pushed 5 images, force-rolled 7 services, 114s. Health endpoint
  returned 200 1.4s post-deploy.
- Ephemeral preview stacks: `rc up --domain <subdomain>.rctest.ezapps.ai`
  brings up a full Django+postgres+redis+celery stack to healthy on
  us-west-1.

## Known limitations

- `rc adopt` blocked on a terraform module-shape mismatch between
  v1_migrate's emitted import addresses and v2 ECSProvider's emitted
  resources — tracked as `rc-zee` and the broader v2-audit beads
  (search `bd ready`). Use `rc deploy --no-state` for hybrid stacks
  in the meantime.
- Django is currently a hard dependency for legacy v1 imperative
  commands. Planned to move under a `[django]` extra in v0.3.x.

## Install + verify

```bash
pip install "remote-compose[ecs]"
rc --help
rc deploy --help
```
